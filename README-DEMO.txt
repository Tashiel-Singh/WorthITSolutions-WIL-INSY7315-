================================================================================
  MEDFLOW: INTEGRATED B2B DISTRIBUTION MANAGEMENT SYSTEM
  STANDALONE ZERO-DEPENDENCY PRESENTATION DEMO
================================================================================

This portable package allows anyone to run the full, interactive MedFlow
demonstration offline on any Windows laptop without installing Node.js,
npm, databases, or external web servers.

--------------------------------------------------------------------------------
QUICKSTART: HOW TO LAUNCH
--------------------------------------------------------------------------------
1. To launch immediately:
   -> Double-click "Launch-MedFlow-Demo.bat"

2. To put an icon on your Windows Desktop:
   -> Double-click "Create-Desktop-Shortcut.bat"
   -> A "MedFlow Demo" shortcut with the MedFlow icon will appear on your Desktop!

--------------------------------------------------------------------------------
KEY PRESENTATION CAPABILITIES
--------------------------------------------------------------------------------
• ZERO EXTERNAL DEPENDENCIES:
  Runs on any standard Windows 10/11 machine. If Node.js is present, it uses
  a high-speed micro-server; if Node is absent, it uses the native built-in
  Windows PowerShell HttpListener.

• NATIVE APPLICATION WINDOW MODE:
  Launches Microsoft Edge or Google Chrome with --app flag, removing browser
  bars for a distraction-free native desktop app presentation.

• IN-BROWSER STOCHASTIC GROWTH ENGINE:
  Run Monte Carlo stochastic simulations (Geometric Brownian Motion) directly
  in memory with interactive Recharts velocity graphs.

• REAL-TIME DUAL-POOL INVENTORY & ATOMIC REALLOCATION:
  Demonstrate Wholesale Bulk Reserve and Retail Dispensary pool segregation.
  Simulate real-time stock transfers with FEFO batch assignment.

• SARS SECTION 11(e) TAX DEDUCTION ENGINE:
  Instantaneous tax shield calculations:
  Total Deduction = (Assets * 20%) + (Expenses * 15%) + (Bulk Revenue * 5%).

• 7-ROLE ENTERPRISE DEMO SWITCHER:
  Seamlessly switch between system personas from the top-right header:
  - Distributor / Owner (Thomas)
  - Pharmacy Manager (Bulk ordering & invoices)
  - Pharmacist (Dispensary & catalog)
  - Doctor / Psychiatrist (Clinical prescriptions)
  - Leisure / Wellness Client
  - Patient (Prescription fulfillment)
  - Compliance Auditor (Regulatory audit trail)

• GLOBAL STATE RESET:
  Press Ctrl + Shift + R at any time, or click the "Reset Demo State" button
  to clear local memory back to fresh clinical seed data.

# Environment stability
| Control | Setting |
|---|---|
| HTTPS | Enforced, Render-managed TLS certificates |
| Health check | GET /health on API, used by Render to route traffic |
| Secrets | Render environment variables; JWT secret generated by Render; env files git-ignored |
| Database | Managed Postgres, internal connection string |
| Deployments | Triggered only by merges to main via GitHub Actions |
| Verification | Post-deploy smoke test polls /health |
| Cold starts | Scheduled keep-alive ping during demo week |

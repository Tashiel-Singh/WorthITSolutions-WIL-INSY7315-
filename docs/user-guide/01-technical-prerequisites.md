# Technical prerequisites and system requirements

MedFlow runs in a web browser. Nothing is installed.

## Supported browsers
Latest two versions of Chrome, Edge and Safari on desktop and tablet (the tested set). Other browsers may work but are not supported.

## Devices (recommended, not benchmarked)
- Laptop, desktop or tablet from the last five years
- At least 4 GB of memory and a display of 1280 x 720 or larger
- Keyboard-only use is supported: the first Tab press reveals a "skip to content" link

## Network
- Outbound HTTPS (port 443) to the MedFlow web address and the MedFlow API address, supplied by your administrator. Corporate firewalls must allow both.
- A stable connection of about 2 Mbps or better is recommended (our recommendation, not a measured minimum).
- JavaScript must be enabled.
- Your device clock must be correct: sessions and expiry alerts depend on it.

## What to expect on first load
The system is currently hosted on a free cloud plan that sleeps when idle. The first page after a quiet period can take up to about a minute. Wait for it to finish, then continue normally.

## Before you start
Have ready: the web address, your work email and the initial password from your administrator.
